# 📊 Mutual Fund Analytics Dashboard using Python, SQLite, and Power BI

## 📌 Project Overview

This project was developed as part of the Bluestock Mutual Fund Capstone Project. It provides an end-to-end analytics solution to analyze mutual fund data, evaluate fund performance, understand investor behavior, and build interactive dashboards for informed investment decisions.

---

## 🎯 Objectives

- Collect and integrate mutual fund datasets.
- Clean and transform raw financial data.
- Store data using SQLite.
- Perform Exploratory Data Analysis (EDA).
- Evaluate fund performance using risk-return metrics.
- Analyze investor behavior and market trends.
- Develop an interactive Power BI dashboard.
- Generate actionable investment insights.

## 🚀 How to Run

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run ETL Pipeline

```bash
python run_pipeline.py
```

### Open Dashboard

Open:

```
dashboard/bluestock_mf_dashboard.pbix
```

using Power BI Desktop.

## 🔍 Key Findings

- SIP inflows increased significantly from 2022–2025.
- Equity funds attracted the highest inflows.
- Investors aged 26–35 years were the most active.
- T30 cities contributed more investments.
- High Sharpe Ratio funds delivered better risk-adjusted returns.
